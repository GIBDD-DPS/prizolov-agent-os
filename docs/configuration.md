# Настройки

Настройки берутся из переменных окружения и файла `.env` в папке запуска (образец —
`.env.example`). Переменные окружения важнее `.env`. Файл `.env` с ключами не
коммитьте в git.

## Модель Claude

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Ключ Anthropic ([console.anthropic.com](https://console.anthropic.com/)). Заглушка из `.env.example` не считается ключом. |
| `PRIZOLOV_MODEL` | `claude-sonnet-5-5` | Модель для всех агентов. |
| `PRIZOLOV_EFFORT` | `medium` | Глубина рассуждений: `low`, `medium`, `high`, `xhigh`, `max`. Выше — точнее, но дороже и дольше. |
| `PRIZOLOV_MAX_TOKENS` | `16000` | Максимальная длина одного ответа модели. |
| `PRIZOLOV_MAX_RETRIES` | `3` | Повторы запроса к API при временных сбоях. |

## Рабочая папка и память

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PRIZOLOV_WORKSPACE` | `workspace` | Рабочая папка: только здесь агенты читают и пишут файлы. Её документы попадают в базу знаний. Здесь же `reports/`, `charts/`, `inbox/`. |
| `PRIZOLOV_DB_PATH` | `data/prizolov.db` | База SQLite: диалоги, факты, уроки, версии промптов, журнал прогнозов, расписание, база знаний. |
| `PRIZOLOV_SELF_CHECK` | `complex` | Самопроверка ответов критиком: `complex` — когда работали специалисты, `always`, `off`. |
| `PRIZOLOV_SIGN_OUTPUT` | `true` | Подписывать авторством файлы `.md`, `.txt`, `.html`, которые создают агенты. |
| `PRIZOLOV_COMPACT_AT` | `150000` | После скольких токенов сжимать старую часть диалога (минимум 50000; `0` — не сжимать). |
| `PRIZOLOV_PARALLEL` | `4` | Сколько поручений специалистам выполнять одновременно (1–16). |

## Расходы и трассировка

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PRIZOLOV_BUDGET_TASK_USD` | `1.0` | Лимит расходов на одну задачу, долларов (`0` — без лимита). |
| `PRIZOLOV_BUDGET_DAY_USD` | `10.0` | Лимит расходов в день. |
| `PRIZOLOV_TRACE` | `true` | Журнал всех шагов агентов: `logs/trace-ГГГГ-ММ-ДД.jsonl`. |
| `PRIZOLOV_TRACE_DIR` | `logs` | Папка журналов. |
| `PRIZOLOV_TRACE_CONTENT` | `false` | Писать полные тексты задач и результатов (могут содержать ваши данные). |

Лимит проверяется перед каждым запросом к модели. При параллельных поручениях он
может быть превышен на стоимость нескольких одновременных запросов. В чате лимиты
меняются командой `/budget task N` или `/budget day N` (до перезапуска).

## Telegram и расписание

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | Токен бота от @BotFather. |
| `PRIZOLOV_TELEGRAM_ALLOWED_IDS` | — | Telegram ID через запятую, которым разрешён доступ. Без них бот не запускается. |
| `PRIZOLOV_TIMEZONE` | `Europe/Moscow` | Часовой пояс расписания (имя из базы IANA). |

## HTTP API

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PRIZOLOV_API_KEYS` | — | Ключи доступа через запятую, каждый не короче 16 символов. Без них API не запускается. |
| `PRIZOLOV_API_HOST` | `127.0.0.1` | Адрес. `127.0.0.1` — только с этого компьютера; `0.0.0.0` — из сети (тогда нужен HTTPS-прокси впереди). |
| `PRIZOLOV_API_PORT` | `8800` | Порт. |
| `PRIZOLOV_API_WORKERS` | `2` | Сколько задач агентам выполнять одновременно (1–16). |
| `PRIZOLOV_PUBLIC_ACCURACY` | `false` | Открыть всем (без ключа) страницу точности прогнозов `/public/accuracy` и `/public/accuracy.json`. На ней видно, по каким активам делались прогнозы. |

## Портфель, MCP

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PRIZOLOV_TINVEST_TOKEN` | — | Токен T-Invest API «только для чтения» (Т-Инвестиции → Настройки → Токены). Нужен для `prizolov portfolio --tinvest`. |
| `PRIZOLOV_MCP_ROOTS` | — | Папки через запятую, из которых MCP-сервер может читать файлы по полному пути (кроме рабочей папки). |

## Логи

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PRIZOLOV_LOG_FILE` | — | Файл логов (кроме вывода в консоль). |
| `PRIZOLOV_LOG_LEVEL` | `INFO` | Уровень логов в файле: `DEBUG`, `INFO`, `WARNING`, `ERROR`. |

Уровень логов в консоли выбирает команда: по умолчанию видны только сбои, с ключом
`-v` (`prizolov -v chat`) — всё.

## Сеть

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PRIZOLOV_TIMEOUT` | `30` | Таймаут запроса к источникам котировок (Yahoo, Мосбиржа, ЦБ) и к ленте госзакупок ЕИС, секунд. |
