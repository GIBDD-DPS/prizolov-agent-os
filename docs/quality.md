# Как проверяется качество

| Что | Когда | Что ловит |
|---|---|---|
| Тесты (`python -m pytest`) | каждый push и pull request | ошибки в коде; сеть и ключ не нужны |
| Стиль, типы, шапки (`ruff`, `mypy`, `stamp_headers.py`) | каждый push и pull request | опечатки, ошибки типов, потерянные шапки авторства |
| Проверка агентов (`prizolov eval`) | раз в неделю и вручную | ответы агентов стали хуже после правки промпта или смены модели |
| Живые источники (`tests/test_live.py`) | каждую ночь | Yahoo, Мосбиржа, ЦБ, ЕИС или T-Invest изменили формат ответа |

## Проверка агентов на настоящей модели

Обычные тесты идут на подставной модели. Они проверяют код, но не качество ответов.
`prizolov eval` решает 16 эталонных задач на настоящей модели и проверяет ответы.

**Какие задачи:**
- кассовый разрыв по выписке;
- выписка 1С;
- сравнение редакций договора и риски договора;
- разбор извещения о закупке;
- прогнозы и портфель;
- база знаний;
- попытка prompt injection в документе;
- письмо клиентам;
- честный ответ на вопрос без ответа.

**Как проверяется каждый ответ:**
- **По правилам.** Задача поручена нужному специалисту, вызваны нужные инструменты, в
  ответе есть нужные факты: например, остаток 463 300 по демо-выписке или обеспечение
  заявки 48 000 по извещению.
- **Моделью-оценщиком.** У задач с критериями отдельный запрос к модели ставит оценку
  от 1 до 10. Проверка пройдена при оценке от 7 и выполнении всех критериев.

**Условия запуска:**
- каждая задача решается в пустой временной папке с чистой памятью;
- котировки — демо-ряды без сети, чтобы оценивались агенты, а не доступность бирж;
- запись файлов и расписание отклоняются.

```bash
prizolov eval --list                 # список проверок
prizolov eval                        # все проверки (несколько минут)
prizolov eval cash-gap contract-diff # выбранные
prizolov eval --no-judge             # без модели-оценщика: дешевле, только правила
prizolov eval --max-usd 3            # остановиться, когда потрачено $3
```

Отчёт сохраняется в `workspace/reports/evals-ГГГГММДД-ЧЧММ.md` и `.json`: что не
прошло, оценка, стоимость каждой задачи. Команда завершается с кодом 1, если хоть
одна проверка не пройдена.

**Сколько стоит.** Зависит от модели. Точную сумму по каждой задаче и итог показывает
отчёт. Лимит на прогон задаёт `--max-usd` (по умолчанию $10), лимит на задачу — $2.
Первый раз удобно запустить одну-две проверки и посмотреть стоимость.

**Запускать нужно из клона репозитория:** задачи берут демо-файлы из `examples/`.

### Раз в неделю в GitHub Actions

Задача «Проверка агентов» (`.github/workflows/evals.yml`) работает так:
- запускается по понедельникам или вручную: Actions → «Проверка агентов» → Run workflow;
- при ручном запуске можно указать проверки и лимит расходов;
- ей нужен секрет `ANTHROPIC_API_KEY` (Settings → Secrets and variables → Actions),
  без него она пропускается;
- отчёт появляется в сводке запуска и в артефакте `evals-report`.

### Своя проверка

Задача описывается в `prizolov_os/evals/cases.py`:

```python
EvalCase(
    id="my-case",
    title="Короткое название",
    task="Задача, как её написал бы пользователь",
    files={"file.txt": "содержимое", "prices.csv": "examples:demo_prices.csv"},
    expect_agents=["lawyer"],                 # кому должен поручить Директор
    expect_tools=["search_knowledge|read_file"],  # "a|b" - любой из
    must_match=[r"48000"],                    # регулярные выражения по ответу
    must_not_match=[r"гарантирован"],
    rubric="1. Критерий для оценщика.\n2. Ещё критерий.",
)
```

Пробелы внутри чисел перед сравнением убираются: «463 300» ищется как `463300`.

## Живые источники

```bash
PRIZOLOV_LIVE=1 python -m pytest tests/test_live.py -rs
```

**Что проверяется:**
- котировки Yahoo, Мосбиржи и ЦБ: данные свежие и правдоподобные;
- лента ЕИС: закупки разбираются вместе с ценой;
- T-Invest: список счетов. Эта проверка нужна только при заданном
  `PRIZOLOV_TINVEST_TOKEN`; токен — только для чтения.

**Как читать результат:**
- **Пропуск.** Источник недоступен из этой сети: нет связи, блокировка, перегрузка.
  Это не ошибка кода. ЕИС часто закрыта для зарубежных серверов, включая серверы
  GitHub.
- **Падение.** Источник ответил, но ответ не удалось разобрать. Значит, пора чинить
  разбор. Неверный токен T-Invest — тоже падение.

Ночная задача «Живые источники» (`.github/workflows/live.yml`) запускает эти тесты
каждый день. О падении GitHub пишет владельцу репозитория на почту. Для проверки
T-Invest добавьте секрет `PRIZOLOV_TINVEST_TOKEN`.
