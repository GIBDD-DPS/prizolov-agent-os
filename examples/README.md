# Примеры

Файлы `demo_*.csv` — **выдуманные демо-данные**, а не реальные цены и не реальная
компания. Они нужны, чтобы попробовать систему за минуту, без ключа Claude и без
интернета.

## 1. Анализ выписки: будет ли кассовый разрыв

`demo_bank_statement.csv` — полгода операций небольшой компании: аренда,
зарплата, налоги, оплаты клиентов, закупки.

```bash
prizolov cashflow examples/demo_bank_statement.csv --balance 3000000 --days 60
```

Что покажет команда:

- поступления и расходы по месяцам;
- крупнейшие статьи расходов;
- ожидаемый остаток через 60 дней с интервалами 80% и 95%;
- вероятность уйти в минус;
- через сколько дней закончатся деньги при текущем темпе;
- два графика в `workspace/reports/`.

Формат своей выписки — CSV или Excel с колонками даты, суммы и (необязательно)
назначения. Поступления — плюс, расходы — минус. Разделитель `,` или `;`, дата
`ГГГГ-ММ-ДД` или `ДД.ММ.ГГГГ`.

## 2. Прогноз по своему ряду цен

`demo_prices.csv` — два года цен условного актива.

```bash
prizolov report --file examples/demo_prices.csv --horizons 1,7,15,30
```

Как строится прогноз:

- четыре метода соревнуются на истории ряда;
- для каждого горизонта выбирается самый точный;
- к прогнозу приложено, на скольких прогнозах проверен метод и как часто факт
  попадал в интервал.

Для реальных котировок файл не нужен: `prizolov report GOLD`, `prizolov report BTC-USD`.

## 3. Те же задачи с агентами

С ключом Claude агенты сами выбирают инструменты, объясняют результат и дают
рекомендации. Агенты работают только с файлами рабочей папки, поэтому сначала
скопируйте выписку туда:

```bash
cp examples/demo_bank_statement.csv workspace/
prizolov run "Проанализируй выписку demo_bank_statement.csv, остаток на начало 3 млн. \
Будет ли кассовый разрыв в ближайшие 2 месяца и что можно сделать? Нарисуй график."
```

## 4. Свой клиент HTTP API

`api_client.py` — клиент на чистом Python: ставит задачу, показывает ход работы,
спрашивает подтверждения и печатает ответ.

```bash
prizolov api &                                    # или docker compose up -d
export PRIZOLOV_KEY=<ключ из PRIZOLOV_API_KEYS>
python examples/api_client.py "Курс юаня ЦБ на неделю"
python examples/api_client.py --report GOLD
```

Справочник по API — [docs/api.md](../docs/api.md).
