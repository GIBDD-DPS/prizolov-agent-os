# Legacy

Архив старого кода Prizolov Agent OS. Не входит в пакет `prizolov_os`, не тестируется и не поддерживается.

- `core/`, `agents/`, `memory/`, `main.py` — система v2.001: выбор агента по `evaluate()`, память MemorySystem.
- `prizolov_director.py` — прототип директора (только печать в консоль).
- `demo.py`, `examples/` — примеры под API, которого больше нет.
- `prizolov_os/agents/` — заглушки ResearchAgent и WriterAgent.
- `prizolov_os/protocols/` — заглушка протокола AWENATING.
- `docs/architecture.md` — старая заметка об архитектуре.

Актуальный код находится в `prizolov_os/`.
