Prizolov Agent OS

Команда ИИ-агентов

Директор распределит задачу между специалистами: исследователь, писатель, финансовый и рыночный аналитики. Ход работы виден по шагам.

Выписка и прогноз остатка

Выгрузка клиент-банка для 1С (.txt), CSV или Excel. Анализ без Claude: статьи расходов, прогноз остатка, день кассового разрыва.

Плановые платежи

Аренда, зарплата, налоги, счета поставщиков (минус) и ожидаемые оплаты клиентов (плюс). По ним строится платёжный календарь.

Отчёт по активу

Прогнозы без Claude: метод выбирается по точности на истории, прогнозы записываются в журнал и потом сверяются с фактом.

Соревнование методов

«Проверено» - на скольких прогнозах по истории проверен метод; «В 80%» - доля фактов внутри 80%-го интервала (цель - около 80%); «Направление» - как часто угадан рост или падение; «Сверено» - реальные прогнозы, срок которых наступил.

Новая задача по расписанию

Например: «ежедневно 09:00», «по понедельникам 10:00», «каждые 6 часов» или cron. Задачи выполняет процесс с планировщиком (prizolov api --scheduler или Telegram-бот).
